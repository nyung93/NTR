# somewhere. — 나트랑 여행 플래너

첨부 여행 플래너를 바탕으로 만든 React + Vite 애플리케이션입니다.

## 실행

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

프로덕션 빌드: `npm run build`

## 기능

- 여행 요약, 항공편과 숙소 카드
- 날짜별 일정, 일정 추가, Google Maps 검색 연결
- 두 여행자의 스파 프로그램 선택 및 이용 횟수 관리
- 일정·스파 선택의 브라우저 로컬 저장
- 데스크톱 사이드 메뉴와 모바일 하단 메뉴

스파 플래너는 개인 여행 계획이며 실제 예약을 전송하지 않습니다. 데이터는 현재 브라우저에만 저장되며 다른 기기와 동기화되지 않습니다. 사용자가 제공한 사타호텔·퓨전리조트·나트랑 해변 사진은 프로젝트에 포함되어 외부 이미지 접근 없이 표시됩니다.
